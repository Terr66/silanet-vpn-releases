# SilaNet VPN — релизы

Официальные установочные файлы приложения **SilaNet VPN** для Android.

Здесь публикуются только готовые сборки, контрольные суммы, история изменений и лицензионные уведомления. Исходный код приложения закрыт.

## Текущий статус: Alpha

| | |
|---|---|
| Последняя версия | [Releases](../../releases) |
| Канал | **Alpha** — предварительная тестовая сборка |
| Android | 8.0 и новее |
| Подключение к серверам SilaNet | **пока недоступно** в alpha-сборках |

Alpha-сборки предназначены для знакомства с интерфейсом и проверки установки. Они **не подключаются** к серверам SilaNet: сервис активации ещё не запущен. Для работы VPN продолжайте пользоваться текущими приложениями (Happ, INCY и др.) по инструкции в Telegram-боте SilaNet.

## Как проверить файл
1. Скачайте APK и `SHA256SUMS.txt` из релиза.
2. Сравните контрольную сумму:
   - Windows (PowerShell): `Get-FileHash .\SilaNet-VPN-*.apk -Algorithm SHA256`
   - macOS / Linux: `shasum -a 256 SilaNet-VPN-*.apk`
3. Alpha-сборки подписаны отдельным тестовым ключом SilaNet. SHA-256 сертификата подписи:
   `DA:CF:D1:95:ED:68:FC:30:7D:D6:32:76:12:C6:DE:4C:12:CB:C1:5D:26:DC:27:67:49:6D:03:02:D2:33:93:5F`
   Проверка (Android SDK): `apksigner verify --print-certs SilaNet-VPN-*.apk`

Будущие официальные (не alpha) версии будут подписаны другим, постоянным ключом и устанавливаются как отдельное приложение.
