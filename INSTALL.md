# Установка SilaNet VPN (Alpha)

## Какой файл скачать
| Файл | Для чего |
|---|---|
| `SilaNet-VPN-<версия>-arm64-v8a.apk` | большинство современных телефонов (рекомендуется, меньше размер) |
| `SilaNet-VPN-<версия>-universal.apk` | если не уверены в модели или arm64-версия не устанавливается |

## Шаги
1. Скачайте APK со страницы релиза на телефон.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или файлового менеджера) — разрешите только для этой установки.
3. Нажмите «Установить».
4. Приложение появится как **SilaNet VPN** (alpha-сборка устанавливается отдельно от будущих официальных версий).

## Что вы увидите
- Пометку «Alpha-версия» на первых экранах.
- Экран активации, где кнопка недоступна: подключение к серверам SilaNet в alpha-сборках ещё не работает.
- Раздел «Лицензии открытого ПО».

## Удаление
Настройки Android → Приложения → SilaNet VPN → Удалить. Приложение не хранит ваших данных вне телефона.

## Требования
Android 8.0 и новее, архитектура arm64-v8a, armeabi-v7a или x86_64 (universal APK).
