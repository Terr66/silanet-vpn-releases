# История изменений SilaNet VPN

## 0.1.0-alpha.1 — 29.10.2026
Первая предварительная сборка для знакомства с приложением.

**Что есть**
- Собственное приложение SilaNet VPN для Android 8+ в оформлении SilaNet.
- Вход по имени подписки с подтверждением кодом из Telegram-бота (интерфейс; в alpha подключение к сервису отключено).
- VPN-туннель на базе Xray-core (VLESS + REALITY), локальный прокси, раздельное туннелирование приложений, защита от утечек DNS и IPv6 — реализованы и проверены на тестовом стенде, в этой сборке пользователю недоступны.
- Разделы «О сервисе», диагностика, управление устройствами подписки.
- Экран «Лицензии открытого ПО».

**Ограничения alpha**
- Подключение к серверам SilaNet пока недоступно.
- Не проверено на большом числе реальных устройств.
- Обновления alpha-версий выпускаются вручную.
